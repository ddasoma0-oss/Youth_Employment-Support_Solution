# 청년 취업 위험군 예측 & AI 기반 맞춤형 컨설팅 시스템

기간: 2026.06 ~ 2026.07, 데이터: 한국고용정보원 청년패널조사(YP) 2024

청년패널조사(YP) 데이터로 취업 성공/실패를 가르는 요인을 분석하고, XGBoost 예측 모델과 LLM, n8n 자동화를 결합해 취업 고위험군 청년에게 개인화된 컨설팅을 자동 생성하는 파이프라인을 구축했습니다.

| 지표 | 결과 |
|---|---|
| 예측 모델 | XGBoost, AUC 0.804 |
| 분석 대상 미취업 청년 | 3,531명 |
| 자동 선별 고위험군 | 735명 (하위 20%) |
| AI 컨설팅 자동 생성 | 20명 샘플 검증 완료 → 전체 확장 가능 |

## 🚫 문제 정의
취업난이 심각한 현재, 청년 취업지원제도는 매년 수십만 명에게 제공되지만, 대상 선정은 여전히 정교하지 않습니다. 한정된 상담 예산으로 최대 효율을 내려면 "지금 가장 취업이 어려운 청년이 누구인가"부터 데이터로 가려낼 수 있어야 합니다.

❓ 취업 성공 청년과 미취업 청년 사이에는 어떤 차이가 있는가? 그리고 그중에서도 지금 가장 우선적으로 도움이 필요한 청년은 누구인가?
→ 한정된 자원을 가장 필요한 청년에게 정밀하게 배분할 수 있는 근거를 데이터로 제시합니다.

## 📕 방법론

### 1) 데이터 누수(Data Leakage) 탐지 및 해결

모델링 전 재검토 과정에서 다음 문제를 발견하고 제거했습니다.

| 문제 | 원인 | 조치 |
|---|---|---|
| 타겟 직접 누수 | eco_status_total로 target_employed를 생성 → 타깃 정답을 그대로 포함 | 컬럼 제거 |
| 데이터 누수 | weekly_work_hours, employment_status가 취업자에게만 값이 존재 → 타깃 변수 힌트 제공 | 컬럼 제거 |
| 과적합 위험 | 식별자 user_id 포함 | 인덱스로 전환 |

전처리는 모델 성격에 맞춰 반복적으로 점검, 보완하는 과정이라는 것을 확인했습니다.

### 4) 분류 임계값 대신 분위수 기준 채택

프로젝트 목적이 "미취업 청년 중 취업 확률이 낮은 청년 대상 개인화 취업 솔루션 제공으로 취업난 해소"이었기 때문에, F1-Score/precision-recall 기반 임계값 조정 대신 예측 확률의 하위 20% 분위수를 고위험군 기준으로 사용했습니다.

## 🤖 AI 자동 컨설팅 파이프라인 (LLM + n8n)
Google Sheets → Loop → AI Agent → Wait(5s) → Code(검증) → Google Sheets Update

- 모델이 도출한 Feature Importance 상위 10개 + 개인별 데이터를 LLM에 입력
- n8n으로 고위험군 개별 청년에게 맞춤 컨설팅 자동 생성
- Code 노드로 컨설팅 결과에 핵심 상담 요소(학력, 프로그램 등) 포함 여부를 PASS/FAIL로 자동 검증
- 검증된 결과를 원본 데이터에 파생변수(AI_솔루션, 검증_여부)로 병합해 최종 데이터셋 산출
#### 검증 방식: LLM API 비용 문제로 고위험군 735명 전체가 아닌 랜덤 20명 샘플로 파이프라인을 먼저 검증했으며, 동일 로직으로 전체 데이터 확장이 가능함을 확인했습니다.

### 솔루션 요약
- 진단: 고졸 + 비경제활동인구 + 정부 지원 프로그램·직업훈련 미참여 + 구직 활동 중단(시험 준비 無)
- 추천 직무·프로그램: 생산/품질관리 보조 or 물류/재고관리 보조 직무 → 국민내일배움카드 연계 + 청년도전지원사업·국민취업지원제도(심리상담 및 진로탐색)
- 로드맵: 1-3개월(고용센터 상담, 프로그램 신청·선택, 훈련계획 수립) + 4-12개월(직업훈련 수료 및 자격증 취득, 취업지원서비스 활용해 구직·취업 연계)
- 기대효과: 단기적으로 구직 의욕 회복 및 명확한 직업 목표 설정, 장기적으로 직무 역량·자격증 확보를 통한 취업 경쟁력 강화 및 경제적 자립 기반 마련

## ✅ 결과 및 기대효과
기존 취업 지원 정책이 "금액 지급"에 집중되어 있던 한계를, 데이터 기반 위험군 선별 + LLM 개인화 조언으로 보완할 수 있음을 프로토타입 수준에서 검증했습니다.

- 이 구조가 실제 서비스로 확장될 경우, 미취업 청년에게 일괄적인 안내 대신 개인의 학력,연령,구직 상태에 맞춘 행동 가이드를 제공함으로써, 청년 개개인이 자신에게 맞는 취업 경로를 더 빠르게 찾는 데 도움이 될 것으로 기대됩니다.
- 한정된 상담 예산을 취업 취약계층에 우선 배분할 수 있어 정책 상담의 효율성이 높아질 것으로 기대됩니다.

## 📍 트러블슈팅 & 회고
### 이슈 원인 해결
- XGBoost 변수명 충돌 앞서 정의한 X, y를 최종 학습 셀에서 재사용하다 충돌 -> df_modeling 기준으로 X, y 재선언
- XGBoost 딕셔너리 언패킹 누락 에러: grid_search.best_params_를 **없이 그대로 XGBClassifier에 넣어서 dict 전체가 objective 파라미터 값으로 들어가버려 에러 발생 → ** 추가해서 해결
- n8n 워크플로우 설계 미숙 -> 첫 자동화 툴 사용 공식문서/구글링 기반 학습 후 적용
- LLM API 비용 부담(고위험군 735명 전체 컨설팅 생성 시 비용 과다) -> 20명 샘플로 파이프라인 우선 검증 후 확장 가능 구조로 설계

- **⭐️ LLM 검증 및 개선 과정**
    1. 하이퍼파라미터 튜닝 결과(max_depth=5)와 실제 최종 모델(max_depth=3)이 불일치       → 재확인 후 최종 모델을 튜닝 결과값으로 재학습
    2. 고위험군 인원수가 문서 내에서 759명/735명으로 혼재 → 코드 출력값 기준으로 735명 통일
    3. '시험 준비 안 함'을 결핍으로 해석하는 **프롬프트 로직이 프로젝트 철학(빠른 취업 우선)과 모순됨을 발견** → 인사이트 문구를 재작성
    4. 변수 y04d001을 'active_job_hunting'(적극적 구직활동)으로 오매핑한 사실을 코드북 대조로 발견 → 실제로는 y04c113이 맞는 변수였으나, 결측치가 많아 해석이 어려워 최종적으로 드랍 결정 → 이 과정에서 카이제곱 분석에 데이터 누수 변수(weekly_work_hours)가 남아있던 것, 하이퍼파라미터 하드코딩, 고위험군 매칭이 행 순서에 의존하던 부분 등을 함께 재점검하고 리팩토링
